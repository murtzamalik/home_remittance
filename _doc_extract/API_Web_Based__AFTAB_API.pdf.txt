Objective
Receiving Agents can integrate their system with Aftab Currency RAgent Web Services, to “receive” the
transactions via Web Service.
Intended Audience
This document is intended for programmers who are already familiar with the web services. This
document does not include general information about web service; it contains the details of integration
with Aftab Currency RAgent Web Service API along with I/O parameters.
Description
Aftab Currency RAgent Web Service API contains following web methods, namely:
1. GetPaymentInfo - Transaction information could be queried, by Payment No.
2. GetPaymentStatus - Transaction status could be queried, by Payment No.
3. SetPaymentStatus - It update the status and info of a transaction.
More methods can be added upon Agents’ request and after reviewing the requirements.

General Information
Parameters
All methods expect a single Unicode string as parameter. This string is based on Object pattern and will
contain the values of different parameters as Object.
Response
All methods return a Result object as response with payment info if required. Various information regarding
status and payment can be retrieved from using properties.

GetPaymentInfo (PaymentNo as string, aceAuthHeader as object)
Method Name: GetPaymentInfo (ByVal p_Parameter as String, aceAuthHeader(Object)).
Description: It gives Information about transaction in Aftab Currency Exchange system.
Parameter: PaymentNo as string, aceAuthHeader as Object are required to get payment information from
Aftab Currency
Exchange’s system.

Transaction object. A Transaction object contains following sub objects/parts.

In case of success, the transaction will show the Remittance status else it will show the Error Code.
Codes
Every Web Method returns a Response containing a number as “Code”. Following are some of these
1000: Success
10004: Branch Information Missing
10005: Invalid Payment information
10006: MTNNum Missing
10007: Authentication Failure
10008: System Updation Error Please Contact To Administrator
10009: DC Rate Not Given
10010: SC Rate Not Given
10011: System error occured. Please contact technical support
Authentication Values
Every Web Method must be provided following values, the detail of the format is coming further
1. userID - The unique identification of a legitimate user of Integrator System in AftabCurrency.
2. userPass - AftabCurrency Password for the user specified above.
3. userKey - Code Assigned to Sender Location in AftabCurrency System.
All four values shall be provided by RemitAnywhere on registration for API usage. These will be test
values.
Once, the integration is approved by our testing staff, Production values will be provided.

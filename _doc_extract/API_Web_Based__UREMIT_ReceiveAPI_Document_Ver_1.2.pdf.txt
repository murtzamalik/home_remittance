Introduction:- 
UREMIT developed an online Application Programming Interface (API) which can be easily integrated in 
any system working on any platform. UREMIT’s payout partner will call UREMIT API from their internal 
software/applications and would be able to pull out the transaction from UREMIT main web based 
remittance system. This API interface interacts with the UREMIT online remittance application in real 
time. This document describe s what the interface i s designed to do and how it can be used. It also 
contains technical information to provide a general working direction for the Payout Partner.  
The Receive API is designed for Payout Partners that require real-time communication and transmission 
of messages via web services or SOA 
Scope of Receive API:- 
This document covers the generic online interface API developed by UREMIT to allow remittance 
transactions to be paid out by Payout Partners using their own systems instead of using UREMIT online 
remittance application interface. This API provides the facility to display and validate the transaction 
details as well as pull out (Payout) the transaction in real time. All the transmission through this API is 
real time and will affect the payout partner account in real time 
Receive API Methods:- 
1. DisplayTranaction:- 
This method is used to request the details of a specific transaction which needs to be pay out.  The 
Payout Partner will provide a UREMIT’s transaction reference number (UTN), and the system will 
validate the request against the business rules for a payout. If valid, API will respond with full 
transaction details. This method contains the following Input and Output parameters 
Input Parameters:- 
 
DisplayTransactionRequest      From Partner To UREMIT  
Field Name Size Type Description 
UniqueID* 10 String Unique ID assigned to Partner 
Password* 20 String Password assigned to Partner  
SecurityKey* 30 String Security Key assigned to Partner  
TransactionNo* 20 String Unique Transaction Reference Number of UREMIT 
* Mandatory Field

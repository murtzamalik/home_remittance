Detailed Application Deployment Manual  
 
A) Web.Config Settings: 
1) Application’s Web Config  
In application’s web configuration file the following details needs to be update according to the 
deployment in environment: 
a) In  following  change the IP of web server will be replace by the current IP address (as 
shown in Fig) in both attribute, (if required changes should be done on of name of the 
folder where service and pool file are reside). 
 
b) Following attribute should be set to “False” in client environment to stop debugging. 
 
c) The following attributes must be change and revalidated in “DSN” key according to the new 
client environment: 
 User ID  Database User Id 
 Password Database User’s Password 
 Initial Catalog Database Name 
 Data Source  Server Name where Database resides

F) Crystal Report Deployment: 
Crystal report 12 required 32bit environment, for this purpose we need to setup separate virtual 
directory on IIS and change link in calling form to view report, the following procedure should 
be follows to deploy Crystal Report (32bit) on Windows 2008 64x environment. 
1) Install Crystal report 12 redistributable kit (cr2008sp3_redist.zip) 
2) Deploy Crystal reports folder at Web server 
3) Set connection string in web config file 
4) Run IIS Manager 
5) Create New Application Pool In IIS Manager 
 
a) At Defined “Crystal Report Application Pool” click on right click and select “Advance 
Setting”:

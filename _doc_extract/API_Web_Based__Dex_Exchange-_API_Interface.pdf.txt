EPS Payment API 
1. Electronic Payment System (EPS) 
Electronic Payment System is a fast, reliable and secure system to transfer money worldwide. 
EPS is a complete web-based, end-to-end, multi-currency and multi-country money transfer 
software system. 
2. EPS Payment API 
This document provides an overview of Electronic Payment System ’s Payment API . EPS 
Payment API provides fea tures for payment detail check,  pay money  against a particular 
payment, get branch n etwork and change password . The system is exposed via a web service 
that operates in real time. 
3. Connectivity 
The service is made available to the Payee Party systems via a Web Service. To acc ess this 
web service the Payee Party  is provided a user name and a password which is required to be 
supplied for each transaction request. Because of the fact that web services are platform 
independent, the system allows for integration with heterogeneous systems developed in any 
technology. 
It has a SOAP based interface which is a worldwide standard. 
4. Security 
Payee Party is provided a user name  (Agent Code) and a password which is manda tory for 
every transaction and  transactions are carried out only after the Payee Agent is authenticated 
using the provided Agent Code and Password. Following are the salient security features of 
the system.  
 
 The system employs industry standard security techniques to prevent disclosure of 
sensitive data and to avoid malicious attacks. 
 The system is capable of using public -private key encr yption between the client and 
the server. 
 The public / private key pairs are changed periodically. 
 All user passwords are encrypted using one way encryption. 
 All communication is done over Secure Socket Layer (SSL). 
 Values input into every field are validated before use. 
 The data access layer will be responsible for SQL injection attacks(i.e., hackers 
attempting to enter SQL statements through application UI fields) (By Using 
Hibernate)

7. API Operations 
Following is the detailed description of all operations implemented in the API along with the 
length and types of their parameters. With the help of these operations payee party can e asily 
get the payment details, pay money, get branch network, and change their password. 
7.1 Get Payment Details 
The use of this operation is  to get the detail of a particular payment. This will help the payee 
party to see the payment details which they want to pay. A success/failure message along with 
Response Code and some other payment credentials will be sent to the payee party  as a 
response of this operation. 
 
7.1.1 Sample Input 
 GetPaymentDetails  Request from Payee Party to EPS 
 
<SOAP-ENV:Body> 
<ns1:GetPaymentDetails> 
<AgentInfo xsi:type="ns2:AgentInfo"> 
<AgentCode xsi:type="xsd:string">PK003</AgentCode>  
<Password xsi:type="xsd:string">1</Password> 
</AgentInfo> 
<PaymentNumber xsi:type="xsd:string">0307101050086</PaymentNumber> 
</ns1:GetPaymentDetails> 
</SOAP-ENV:Body>

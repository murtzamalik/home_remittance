ICWebService (ICWS) 
 
 
Objective 
Agents can integrate their system with Instant Cash to Receive, Update or Query the transactions via 
XML Web Service. 
 
Intended Audience  
It is assumed programmers are familiar with the xml web service. This document does not include 
general information about web service; it includes the details of integration with ICWS API along with 
Input/output parameters.  
 
Detail Description 
Once the agreement signed between agent and instant Cash(IC) then following procedure will 
complete by our operation and account dept. 
 
1)  IC operation Dept. will create agent’s profile, user login and defined necessary parameters in 
the system. 
2)  Account Dept. will create necessary settlement accounts in the system. 
3)  We will add your mail id in our mailing list to notify about agent’s  
Addition/Modification/Deactivation/Activation.  
 
Once the above procedure completed in system then you can start using below given API in your 
system for integration.  
 
Agent Integration through ICWS API contains 5 web methods  for receiving agents out of 11 major web 
methods . This document describes about 5 web methods  needed for receiving payment integration. 
 
1.  GetOutstandingRemittance  
2.  ConfirmTran  
3.  GetIctcPayStatus   
4.  Reconcile  
5.  ReceivePayment  
6.  UnlockIcTran

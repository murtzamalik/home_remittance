Project Approach
JS Bank embeds RCCC components with Integration Software. RCCC embedded application can directly send/receive messages from PRISM server. Settlement confirmations/error messages can be easily received by the RCC embedded application.  Integration Software will be making a copy of all the messages exchange in between RCC embedded application and PRISM server. RCCC components installed on JS Bank computer.
However, since the JS bank has opted option of RCCC (Remote Client Communication Component); therefore JS Bank is going to develop “INTEGRATION SOFTWARE” to cater the need of “API” which currently provided by SBP as part of PRISM to perform multiple functions, which includes but not limited to authorization of MT102, MT103, MT202, Balance enquiry, monitoring of inflows and outflows, free format messaging and any other functionality which is currently available in the PRISM API provided by SBP Upon receiving the RTGS instructions from any of the partner application, the integration software, will convert the message based on its payment type (as per SBP’ prescribed formats of MT-102, MT-103 and MT-202) and push the outward MTs to PRISM by following

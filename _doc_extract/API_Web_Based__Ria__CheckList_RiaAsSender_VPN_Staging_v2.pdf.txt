Checking common problems using VPN to connect with RIA Web Services 
Contract IRiaAsSender in Staging Environment 
 
1- Host:  Check that in hosts file is included the following IP Address. 
 
10.30.99.5  stagingfxglobalwebsvcnocert.riaenvia.net 
 
2- Ping:   Check that ping command does not return errors. In case of errors, may be a  
proxy  / Firewall problem. 
 
cmd>  ping stagingfxglobalwebsvcnocert.riaenvia.net  –n 100 
 
3- Telnet:  Check that it is possible to connect through Telnet. In case of errors, may be a  
proxy  / Firewall problem.   
cmd> telnet  stagingfxglobalwebsvcnocert.riaenvia.net 9771 
 
4- Create Service reference at Visual Studio project:  
Right click at References and click on Add Service Reference…

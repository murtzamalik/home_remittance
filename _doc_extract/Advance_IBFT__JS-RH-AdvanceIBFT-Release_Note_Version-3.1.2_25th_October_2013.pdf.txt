2.1 Acquisition   
 
2.1.1 Transaction Initiation with CRM Profile Integration 
 
Customer and beneficiary profiles are now available for selection for remittance transaction 
capturing through Transaction Initiation interface 
• On selection of new customer user can proceed without any selection. 
• On selection of existing customer user must select customer from the list otherwise will not 
be able to proceed. 
• On selection of existing customer user can select its existing beneficiary or can create a new 
one. 
• On selection of existing beneficiary user must select beneficiary from the list otherwise will 
not be able to proceed. 
• Customer and beneficiary information will be fetched from their respective profiles on 
selecting existing customer and beneficiary respectively. The profile details fetched will be 
displayed on remitter and beneficiary tabs respectively. 
 
Menu Option: Transaction Initiation

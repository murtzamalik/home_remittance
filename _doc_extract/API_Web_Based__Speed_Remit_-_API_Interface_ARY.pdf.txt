Introduction 
Speed Remit has developed an online Application Programming Interface (API) for partners that would payout 
transactions (Payout Partners) initiated in Speed Remit’s send network. This API interface interacts with the Speed Remit 
Agent Internet System in real time. This doc ument will describe what the interface is designed to do and how it can be 
used. It also contains technical information to provide a general working direction for the Payout Partner.  
The Payout API is designed for Payout Partners that are able to exchange  information via web services, and require real-
time communication. 
Scope of payout API 
This document covers the generic online interface developed by Speed Remit to allow money transfer transactions to be 
paid out by Payout Partners using their own systems rather than Speed Remit’s Agent Internet System as a front end. 
API Methods 
1. ShowTransfer  
This method will be used by the Payout Partner to request the details of a specific tra nsaction which they wish to pay 
out. The Payout Partner will provide a  Speed Remit transaction reference number, or other partner -specific payout 
number, and the system will validate the request against the business rules for a payout. If valid, the f ull transaction 
details will be returned.  
 
2. PayoutTransfer 
This message will allow the Payout Partner to send an update for a Speed Remit cash transaction, for which they have 
previously obtained the details using the Show Transfer. Reasons for update would include:  
• Payout - This will be validated against the business rules for paying transactions. It is the equivalent of the Payout 
screen.  
3. ChangePassword 
This message will allow the Payout Partner to change user’s password and return the response code. 
4. ListTransfers 
This method will be used by the Payout partner to list all UnPaid transactions to a particular account.
